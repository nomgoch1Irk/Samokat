# Electric Scooters — мод электросамокатов (Minecraft 1.20.1, Forge)

Зависимости: **только Minecraft Forge 47.x**. GeckoLib и Kotlin for Forge не используются —
модель самоката собрана на ванильных `ModelPart`.

## Как получить .jar

Готовый .jar собирается из этих исходников (нужен доступ к Maven-репозиториям Forge/Mojang).

**Вариант 1 — на своём компьютере** (JDK 17 + интернет):

```bash
./gradlew build          # Windows: gradlew.bat build
```

Файл появится в `build/libs/escooter-1.0.0.jar` — положите его в папку `mods` клиента
(и сервера) с установленным Forge 1.20.1.

**Вариант 2 — без установки чего-либо, через GitHub:**
1. Создайте пустой репозиторий на github.com и загрузите в него содержимое этой папки
   (вместе со скрытой папкой `.github`).
2. Вкладка **Actions** → **Build mod jar** → дождитесь зелёной галочки (2–5 минут).
3. Внутри запуска, раздел **Artifacts** → `escooter-jar` — там лежит готовый .jar.

Тест из исходников: `./gradlew runClient`. Версия Forge — в `gradle.properties`
(`forge_version=47.4.0`), можно заменить на любую другую 47.x.

## Игровой процесс

Два цвета самоката: **жёлтый** и **фиолетовый**. Цвет задаётся красителем в рецепте.

| Предмет | Рецепт |
|---|---|
| Батарея | медный слиток сверху; два нижних ряда: железо–редстоун–железо |
| Жёлтый / фиолетовый электросамокат | верхний ряд: жёлтый / фиолетовый краситель (по центру) и рычаг (справа); средний: железный слиток справа; нижний: чёрная шерсть–батарея–чёрная шерсть |

* **Поставить** — ПКМ по блоку с самокатом в руке.
* **Сесть** — ПКМ по самокату. **Слезть** — Shift.
* **Управление**: `W` — разгон, `S` — тормоз / задний ход, `A`/`D` — руль.
  Максимум ≈ 9 блоков/сек, заезжает на ступеньки в 1 блок.
* **Заряд**: расходуется только пока держите `W`. Полная батарея ≈ 5 минут газа. Процент виден над хотбаром.
  ПКМ по самокату с батареей в руке — зарядка на 100 %.
* **Забрать** — ударить самокат. Цвет и заряд сохраняются в предмете.
* Скрафченный самокат приходит заряженным на 50 %. В креативной вкладке «Электросамокаты» оба цвета заряжены полностью.

## Структура

```
src/main/java/com/escooter/
  EScooterMod.java                  точка входа
  registry/                         предметы, сущность, творческая вкладка
  item/ScooterItem.java             предмет (ставит сущность, хранит заряд в NBT)
  entity/ElectricScooterEntity.java физика, управление, заряд, цвет
  client/                           модель, рендерер, регистрация (только клиент)
src/main/resources/                 текстуры, модели, рецепты, переводы (en/ru)
tools/make_textures.py              генератор текстур (цвета — словарь COLORS)
.github/workflows/build.yml         автосборка .jar на GitHub
```

## Настройка под себя

* Скорость, разгон, поворот, ёмкость батареи — константы в начале `ElectricScooterEntity.java`.
* Новый цвет: добавьте его в `COLORS` в `tools/make_textures.py`, константу `VARIANT_*` в сущности,
  предмет в `ModItems`, текстуру в `ScooterRenderer`, модель предмета, рецепт и перевод.
* Рецепты — JSON в `data/escooter/recipes/`.
